# Design Reference Set

هذه الصور هي المواصفة البصرية المرجعية للتحديث v1.1 وليست أصولًا تُعرض داخل التطبيق.

- `home_reference.png` — الصفحة الرئيسية.
- `orientation_reference.png` — قبل أن تبدأ.
- `simulation_hub_reference.png` — قائمة المحاكاة.
- `simulation_detail_reference.png` — أوضاع المحاكاة.
- `gcat_exam_reference.png` — GCAT في وضع الامتحان.
- `likert_training_reference.png` — PQ10 / Derailers بدوائر التقييم.
- `leadership_training_reference.png` — الحكم القيادي بدوائر التقييم والشرح.
- `results_reference.png` — النتائج والتقدم.
- `source_examples/` — لقطات Podium التي قدمها المستخدم كمرجع لتجربة الاختيار.

قاعدة الاعتماد: التصميم البرمجي يستلهم الترتيب، النسب، لغة الألوان، شكل البطاقات والدوائر، ولا ينسخ واجهة Podium حرفيًا.
